# docs/archive — retired documentation

These docs are **historical**. They are kept for provenance and git-blame continuity but are
**not maintained** and should not be treated as current.

What lives here:
- **Completed plans** — feature/phase plans whose work shipped (cross-referenced to merged PRs).
- **Dated snapshots** — point-in-time audits, QA passes, handoffs, diagnostics, ideation sessions.
- **Superseded docs** — plans/designs replaced by a newer approach.
- **`superpowers/`** — auto-generated plan/spec artifacts from the superpowers plugin workflow.

Paths mirror the original `docs/` layout. For the list of *living* docs, see
[`../README.md`](../README.md).
