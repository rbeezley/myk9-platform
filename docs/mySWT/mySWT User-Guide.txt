1 Introduction 

1.1 Thank you! 

First let me sincerely thank you for purchasing mySWT (my Scent Work Trial). I believe you 
will find it to be a useful and helpful tool in administrating Scent Work Trials. 

1.2 Application Overview 

The mySWT application is a desktop software application that assists with all of the 
administrative tasks of holding a Scent Work trial. The application and data are stored on 
your local PC, so there is no concern with data privacy. 

A few of the major features are: 

 Record all of the required information of an exhibitor. 
 Record the trials and Classes an exhibitor has entered. 
 Track judges and steward information. 
 Print check-in sheets for the gate steward. 
 Print prefilled score sheets for the judge 
 Record the results within the application as it is happening. 
 Automated calculation of placements. 
 Automated population of AKC Results Catalog. 
 Automated population of AKC Trial Chairman and Trial Secretary Reports 
 Print various Trial statistics such as number of Classes, number pass/fail and high 
in trial. 
 Print Exhibitor Armband Labels. 
 Print Exhibitor Result Labels 
 Email Exhibitor confirmation of their entry, results and an invitation to your next 
trial

3 Application Use 

The sections below explain the general use of the mySWT application. They are in the order 
that you should follow for the first time use and setup of the application. 

 

3.1 First Time Launch 

The first time mySWT is started it will prompt you for the location of the three data files 
(mySWT_data.aacde and myShare.accdb and License.accdb). 

 The mySWT_data.accdb file contains information about your Scent Work shows, 
trials, Classes and entries. 
 The myShare.accdb file contains information about your club, exhibitors (dogs), and 
people (owners, handlers, judges, stewards, and users). 
 The mySWT_License file contains your License information. 


The default location is C:\mySWT {version #}\data. Simply select the file being requested in 
the Title of the dialog box and click open. 

If mySWT is ever moved to another location or it cannot find the data files for some reason 
you will be prompted again for their location.

3.3 Networked Installation 

It is possible to install mySWT in a multi PC environment where PCs are networked 
together. This will require some advanced computer knowledge and is beyond the 
scope of this document. 

It is beyond the scope of this document to explain how PCs can be networked together, but 
the two most common ways would be a homegroup or a shared drive. You can google these 
two terms to find information on how to accomplish this. If you already have or have set up 
this type of environment make sure both PCs have full permissions (read and write) to 
the location where the mySWT_data.accdb file will be stored. 

The advantage of this type on installation is the mySWT application could be running 
simultaneously on two different PCs and both would be storing their data in a single data 
file. This would allow you to be doing tasks such as printing judge’s books or result labels or 
getting ready for the next trial on one PC while the other PC is in the ring recording the 
scores and times of Classes at the same time. The other use would be for a PC just displaying 
the Scoreboard. 

mySWT would be installed on two different PCs. You would use the same setup.exe file and 
license key you downloaded. One of the PCs need to be classified as the primary. It will host 
the mySWT_data.accdb file. The second PC will be classified as the secondary and needs to 
be linked to the data file on the primary. This can be done by using the Re-Link Data File 
button on the login screen. 

Test the setup by starting mySWT on both PCs. Make a change to something on the primary 
PC, say to an exhibitor’s address or phone number. View that same exhibitor on the 
secondary PC and make sure you see the new information. Do the reverse to make sure you 
can make changes on both PCs and the other PC can see those changes. 

I would recommend that you rename the mySWT_data.accdb file on the secondary PC to 
something like mySWT_data_secondary.accde or mySWT_data_NotUsed.accde to avoid any 
confusion. This data file will not be used.

3.4 Terminology 

The table below gives the definition of some of the terms and conventions used 
throughout the mySWT application. A good understanding of these terms will help in 
using the application more efficiently. 

Show 

The term used to define the entire event which could consist of one or 
more days. A show will contain one or more trials. Typically, a show will 
be held over a weekend and contain a morning and an afternoon trial each 
day. 

Trial 

The term used to define a set of Classes. A trial will be assigned to a show. 

Exhibitor 

An exhibitor is a dog and handler team that is competing in a Class. 

Score 

The score is the exhibitor’s result of that Class. For example, pass, false 
alert or absent. 

Fault 

A fault can be given to an exhibitor by the judge for a handler error such 
as guiding the dog or a safety violation. Faults are used in calculating 
placements. If you see a faster time but lower placement on an AKC form, 
it is due to a fault. 

Class 

A class is an overall term that includes the Element, Level and Section. For 
example, container Novice A. 

Element 

An element is a type of search such as Container, Interior, Exterior, Buried 
or Handler Discrimination. 

Level 

A level is the level of the Class such as Novice, Advanced, Excellent, 
Master. 

Section 

The section is A or B. See rules for criteria. 

Run Time 

The run time is the amount of searching time to find all hides in that Class. 
The run time is paused when the handler calls alert and then restarted 
when the handler gives the search command for the next hide. 

Hide 

The location of the hidden odor for which the dog is searching. 

Record 

A database entity. For example, each exhibitor, each show, each trial, each 
Class, etc., would be a record in the database. 

Status 

Shows, Trials and Classes are all assigned a status of either open or closed. 
This status is used throughout the system for determining what choices 
are given. For example, only open Classes are presented for entering an 




exhibitor. It is important to update the applicable status as the show 
progresses. 

System 
Hierarchy 

The hierarchy of the system is Shows contain Trials. Trials contain 
Classes. Classes contain Exhibitors. It is important to keep this concept in 
mind when setting up your shows. 

Bold Field 
Label 

A field label that is bold and contains an asterisk is a required field and 
must be entered in order to save that record. For example, you cannot 
enter a new exhibitor without providing a AKC Registration number, 
register name, breed and handler name. 

Drop Down 
box or 
Combo Box 

A graphical control element, similar to a list box, that allows the user to 
choose one value from a list. When a drop-down list is inactive, it displays 
a single value. When activated, it displays (drops down) a list of values, 
from which the user may select one. When the user selects a new value, 
the control reverts to its inactive state, displaying the selected value. It is 
often used in the design of graphical user interfaces, including web design. 

 

List Box 

A graphical control element that allows the user to select one or more 
items from a list contained within a static, multiple line text box. The user 
clicks inside the box on an item to select it. A list box is always expanded 
unlike a drop down box. 

 

 

Ribbon 

 

In computer interface design, a ribbon is a graphical control element in 
the form of a set of toolbars placed on several tabs. In 2007 Microsoft 
products introduced a form of modular ribbon as their main interface 
where large tabbed toolbars, filled with graphical buttons and other 
graphical control elements, are grouped by functionality. Such ribbons use 




tabs to expose different sets of controls, eliminating the need for many 
parallel toolbars. Contextual tabs are tabs that appear only when the user 
needs them. For instance, in a word processor, an image-related tab may 
appear when the user selects an image in a document, allowing the user to 
interact with that image. 

Application 
File 

The application file is named mySWT_application.accde. This is a 
compiled access file and contains all the forms, queries, reports and visual 
basic code. 

Data File 

The data file is named mySWT_data.accdb. This is also a compiled access 
file and it contains all of the tables and your data. This file is unique to 
your installation. 

Field Labels 

Bold labels with an asterisk * are required fields and must be entered.

3.6 Navigation 

 The primary navigation of the application is accomplished from the home page 
ribbon. Each button in the View section of the Ribbon will take you to the 
corresponding page. Each page has a customized ribbon as mentioned earlier to 
accomplish tasks specific to that page. The large icon choices will be the ones used 
most often. The small icon choices are more supporting type pages that will be used 
less often. 


 

 


 The secondary form of navigation is accomplished by using the record navigation 
buttons at the bottom of each screen when applicable. Think of these navigation 
buttons like a VCR or tape player where the far left button takes you to the first 
record, the next button to the right takes you to the previous record, the first button 
to the right of the record count takes you to the next record, the next button to the 
right takes to the last record and the far right button when enabled takes you to a 
new record.

3.20 Using the Application during a Trial 

The Trial and Classes pages will be the primary pages used during the running of a trial. 

3.20.1 Setup 

Ensure the Show, Trial and Classes are set up. The normal sequence to follow is: 

1. Add a Show 
2. Add Trials and Classes to that Show 
3. Add any new Exhibitors 
4. Enter the Exhibitors in their Classes 


3.20.2 Classes 

 

The exhibitors entered in that Class will be initially listed in armband number order in the 
list at the bottom of the screen. Each time a dog is scored, the placements for the class are 
calculated or re-calculated. The list will then be re-sorted first by Placement and then by 
Armband number. This sorting causes the next dog to run to be at the top of the list 

Follow the procedure below to record each Dog’s Run Time and Faults. 

1. Open the Classes Page 
2. Ensure that the correct Class is displayed. The dogs entered in that Class will be 
listed in armband number order in the list at the bottom of the screen. 


 

3. Click the Enter Results Link for the Dog that is about to run. The Results Dialog box 
will open. The Armband number will be displayed in the upper right corner, so you 



can ensure that you are recording results for the correct dog. 


 

4. When the handler gives the search command and the dog or handler crosses the 
start line click Start button on the Run Time Stopwatch. The button label will 
change to Stop and the time will begin to increment. 
5. When the handler calls alert, click the Stop button on the Search Time Stopwatch. 
6. Record the search by selecting the appropriate Area checkbox. Area 2 and 3 will be 
grayed out except for Interior excellent and master which have multiple search 
areas. The Search Time can also be manually entered by typing in ALL 6 digits using 
leading zeros of the time (mm:ss:hh). Do not type the colons. For example, if the 
time was 1 minute and 30 seconds you would type 013000. 
7. Check the appropriate Result. A reason must be selected for NQ, Excused and 
Withdrawn. 
8. Record any faults by entering a number in the appropriate Fault box or using the 
up\down arrows. 



9. Click Save and Close. 


 

10. Call for the next exhibitor listed which will be the first row. 
11. If an exhibitor is absent, mark them absent on the score dialog box. 
12. After all exhibitors for that Class are scored, print the Results Catalog for that Class. 
Results for ALL dogs entered in that Class should be recorded before printing the 
Results Catalog. 
13. Close out the Class by clicking the Close Out Class button on the ribbon. 
14. If all Classes for the trial are complete, go to the Trials page and print the Trial 
Statistics report and then click Close Out Trial. The Trial Statistics report lists the 
High in Trial winners. 
15. If all trials are complete for the show, go to the Show page and print the Show 
Statistics report and then click Close Out Show.
