# MYK9-492: enforce operator push holds

## Scope

Install a tracked `pre-push` hook that checks trusted push directives on PRs, including closed PRs, before any ref leaves a checkout. A hold on one PR applies to the repository, including a branch's first push. Use the same author-association trust set as the review gate. A fresh `PUSH HOLD: <reason>` or `PUSH RELEASE` comment is the one-step set/release control; the newest trusted directive wins by creation time. Recognize the incident's exact "Hold all pushes until further notice" wording as a hold. Fail closed if GitHub state cannot be read or the bounded history scan cannot establish a directive. Do not post review evidence from the hook.

## Implementation

1. Add a small TypeScript evaluator and CLI to page through repository issue comments newest first, validate directive candidates belong to PRs, and return a clear nonzero refusal. Compare the full newest directive timestamp bucket by comment ID, including page boundaries; fail closed after 2,000 comments if it cannot establish a complete ordering.
2. Add the hook, passing Git's pushed refs to the evaluator, and document its activation and release contract.
3. After the overlapping shared-rules PR merges, update `docs/agents/shared-rules.md` and run `pnpm qa:shared-rules:write`.
4. Roll out the merged hook to active worktrees and verify each one's effective `core.hooksPath` and installed `pre-push` before marking the issue Done. A checkout left on an older commit remains unguarded.

## Testing

1. Add behavioral tests for trusted/untrusted comments, same-second directive ordering across a page boundary, multiple refs, first pushes, holds on closed PRs, releases on closed PRs, bounded pagination, and GitHub failure.
2. Use an actual local `git push --dry-run` through the installed hook with stubbed GitHub responses: a hold must block the push with its reason and no evidence comment; release must allow it.
3. Run focused Vitest, shell syntax check, TypeScript check, formatting, and the code-quality ratchet.
