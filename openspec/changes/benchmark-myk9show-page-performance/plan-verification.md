### Interpretation

The current report is **provisional**. All admin-user attempts now measured, but Show Day and ringside had 12 blocked attempts. Ringside class selection did not produce a usable Slow 4G sample, and ringside scoring produced only one usable Fast 4G cold sample. A 30-second readiness timeout while the app loaded is evidence of a blocked measurement, not a measured load time. No blocked route is ranked as fast.

Among measured cold Slow 4G secretary routes, Show Day had a 23,877 ms median from two runs, Reports 20,478 ms from three, and Setup 18,824 ms from three. The ringside scoring Fast 4G cold median of 27,169 ms has only one measured run and must not be treated as stable. The shared 3.54 MB minified entry chunk transferred 1,125,279 bytes in every measured cold attempt, making initial JavaScript delivery a follow-up candidate; the benchmark alone does not prove a particular import is causal. Genuine warm-cache behavior remains unmeasured under the read-only routing guard.
