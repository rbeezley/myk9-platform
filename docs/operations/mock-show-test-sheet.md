# myK9Show Mock Show: Test Sheet

Thank you for testing. This is a practice run of a whole show, start to finish. No real money moves, and nothing you do can break anything.

**What we most want to know:** where you got stuck, what you had to guess, and where paper would have been quicker.

## Before you start

Richard sets these up for you: your club, your sign-in, and test payments.

**Two rules for the test:**

- **Do not type exhibitors' real email addresses.** The app sends real emails. Leave the email blank, or use your own.
- **Pay only with the test card:** 4242 4242 4242 4242, any future date, any three digits, any ZIP code.

## The tasks

Use the entries from a show you have already run. Tick each task and write down how long it took.

| ✓   | Task                                                                                                                                | Minutes |
| --- | ----------------------------------------------------------------------------------------------------------------------------------- | ------- |
|     | **1. Set up the show.** Two trials, with the classes and judges from your past show.                                                |         |
|     | **2. Publish it** and open entries.                                                                                                 |         |
|     | **3. Key in 10 mail-in entries** with Add entry. Include one exhibitor and dog who are new, and one cheque that came in the post.   |         |
|     | **4. Enter online as an exhibitor.** Sign up with a second email address of your own, add a dog, enter two classes, pay by card.    |         |
|     | **5. Enter two dogs for one owner in the same class**, online.                                                                      |         |
|     | **6. Change something.** Move one dog to another class. Withdraw one dog and decide its refund.                                     |         |
|     | **7. Get ready for show day.** Print the judge's paperwork and the catalog. Find the access codes for your judges.                  |         |
|     | **8. Score one class at Ringside on a phone**, using a judge's code. Halfway through, switch the phone to airplane mode, then back. |         |
|     | **9. Correct one score** after saving it.                                                                                           |         |
|     | **10. Score one class on paper**, then enter those results.                                                                         |         |
|     | **11. Check the results.** Do the placements match what you worked out by hand?                                                     |         |
|     | **12. Finish the show.** Print the results and whatever you would send to AKC.                                                      |         |

## For each task, write down

- **Where you stopped and didn't know what to do next.** The screen, and what you were looking for.
- **Any word or message you didn't understand.** Copy it exactly.
- **Anything that looked wrong:** a name, a number, a total, a time, a placement.
- **Anything you had to do twice.**
- **Where paper would have been quicker,** and why.

A photo of the screen with your phone is the best note you can send.

## Three questions at the end

1. Would you run a real show on this? If not, what is the one thing that stops you?
2. What did you expect to find and couldn't?
3. Would your judges score on a phone after seeing it? What would they say?
